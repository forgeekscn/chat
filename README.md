# 纺大夜跑团应用

## 项目简介

这是一款专门为我校同学定制的健身交友类型应用。旨在帮助同学们通过跑步锻炼身体、缓解学习压力，并在运动过程中结识志同道合的朋友，让运动更加有趣和有动力。

## 核心功能

- **实时定位**：使用网络或GPS定位，每秒刷新一次位置信息
- **跑步路线绘制**：点击开始后，随着用户移动，地图会自动绘制红色路线轨迹，并实时计算速度、路程和时间
  ![应用截图](/pic/a1.jpg)  ![应用截图](/pic/a2.jpg)
- **用户实时显示**：地图上以红色图标显示当前活跃用户，点击可查看用户详情，支持查看主页、添加好友、发送私人消息等功能
- **社交功能**：用户可以编辑个人信息和头像，展示在个人主页，并与好友进行私信交流
  ![社交功能截图](/pic/a3.jpg) ![社交功能截图](/pic/a4.jpg) ![社交功能截图](/pic/a5.jpg)
